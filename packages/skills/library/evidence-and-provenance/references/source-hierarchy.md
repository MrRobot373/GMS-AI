# Source hierarchy

Use the highest source that actually contains the claim.

1. Task files, workbook cells, commits, and system records the user pointed at.
2. Organization documents attached to the task, with their revision or date.
3. Standards, datasheets, and policies the user supplied. Cite the identifier and revision, not a reconstructed clause.
4. Web pages, with URL and the date retrieved. A page the agent remembers but did not open in this task is not this tier.
5. Model knowledge. Status is `assumption` unless a higher tier supports it.

Freshness: if the user names a period ("this quarter", "the latest datasheet"), a source that does not show its date is `unsupported` for that claim.

Disagreement: report both locations. Do not blend figures. Precedence comes only from a rule in the task.

Quotation: a short excerpt is enough. Do not paste a full standard, article, or contract.
