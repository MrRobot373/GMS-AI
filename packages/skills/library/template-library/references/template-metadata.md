# Template metadata to record

No templates are bundled with this skill. When the user supplies one, capture:

- template id and title
- version and effective date, or `user-supplied` and the file’s modified date
- owner, if the file or the user states one
- locale and confidentiality, if stated; otherwise `not specified`
- required fields that were filled and fields left blank
- locked text the agent did not change
- output filename
- a note that no rendering baseline was shipped with the skill

Do not invent an id. The path plus a hash is enough when the file has no id.
